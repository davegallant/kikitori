# Local Podcast Transcriber Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run a local app that accepts a Pocket Casts episode URL, saves audio and bilingual Whisper transcripts, and makes episodes playable and searchable.

**Architecture:** A FastAPI server stores each episode in a filesystem directory and queues work to one background thread. A resolver obtains audio metadata, a downloader verifies media, and a transcription service writes timestamped Japanese and English outputs. Server-rendered pages show the library and episode detail.

**Tech Stack:** Python 3.13, FastAPI, Jinja2, httpx, PyAV 15, faster-whisper, uv, pytest, vanilla JavaScript/CSS; Nix development shell for native runtime libraries.

**Spec:** `docs/superpowers/specs/2026-10-12-local-podcast-transcriber-design.md`

## Global Constraints

- Work in `/home/dave/src/github.com/davegallant/podcast-transcriber` and commit increments on `main`; do not push.
- Bind `127.0.0.1:8765` by default; use filesystem storage under a configurable local data directory.
- Keep downloaded audio and both transcript formats; use `faster-whisper` small, `language="ja"`, `word_timestamps=True`, CPU `int8`.
- Process one job at a time. Recover interrupted jobs on restart and report failures without retry loops.
- Support full Pocket Casts episode URLs and direct HTTP(S) audio URLs; isolate the undocumented Pocket Casts lookup.
- Reject non-audio responses, internal network targets, oversized downloads, and duplicate submissions.

## Review Focus

- A URL that redirects to a private/local address must be rejected before requesting it (Task 1).
- A Pocket Casts page or lookup with a missing target episode must fail clearly (Task 1).
- A failed or non-audio download must not create a completed episode (Task 1 and Task 3).
- Restart during transcription must leave a recoverable job and no partial completed transcript (Task 3).
- Searching Japanese or English text after a restart must return the saved episode (Task 2 and Task 4).
